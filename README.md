# Exploratory Data Analysis on Social Media Usage Patterns

## Overview
This project was carried out as part of 'ST1009 - Exploratory Data Analysis' during the 1st year, 1st semester at the Faculty of Science, University of Colombo. We analyzed the "Time-Wasters on Social Media" dataset sourced from Kaggle to explore social media behavioral patterns across demographic groups.

## Objectives
- Identify key motivations behind social media usage
- Explore platform and content preferences across genders
- Understand time spent patterns across different age categories

## Dataset
- **Source:** Kaggle : Time-Wasters on Social Media
- **Type:** Survey-based behavioral dataset
- **Variables include:** Platform, gender, age, watch time, usage reason, video category, device type

## Tools Used
- **Minitab** - statistical analysis and chart generation

## Key Findings
- Habit was the dominant reason for social media usage (33.9%), not content interest
- TikTok was the most used platform among male users; Instagram among female users
- Majority of users access social media via smartphones, reinforcing habitual usage patterns
- A significant portion of users showed signs of addictive usage behavior impacting daily productivity
